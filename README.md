# Практическая работа №7: Подключение и работа с Redis (кэширование)

## Описание проекта
Учебный проект на языке Go, демонстрирующий базовую работу с in-memory хранилищем **Redis**. 
Приложение реализует простой HTTP-сервер, который умеет сохранять данные в кэш, извлекать их оттуда и проверять время жизни ключа (TTL).

## Функционал
Сервер предоставляет три эндпоинта:
*   `GET /set?key=...&value=...` — сохраняет значение по ключу с TTL 10 секунд.
*   `GET /get?key=...` — извлекает значение по ключу (если оно ещё не удалено).
*   `GET /ttl?key=...` — показывает, сколько секунд осталось до автоматического удаления ключа.

## Стек технологий
*   **Язык:** Go (Golang)
*   **База данных (кэш):** Redis
*   **Библиотека для Redis:** `github.com/redis/go-redis/v9`
*   **HTTP-сервер:** стандартный `net/http`
